Ejecución desatendida

Inicio automático

  1. Guarda las credenciales cifradas.
  2. Ejecuta Install-Automation-Startup.bat.
  3. El motor iniciará con tu sesión de Windows.

El cifrado DPAPI solo permite descifrar las credenciales con el mismo usuario de Windows.

Checklist

Antes de activar producción

  • Comienza con Dry Run.
  • Usa perfiles y queues de laboratorio.
  • Define umbrales distintos para activación y recuperación.
  • No uses las credenciales personales de un supervisor activo.
  • Revisa los CSV dentro de la carpeta logs.
